# 2026_diatom_summer_school
Repository containing script and data for the exercises on diatom biomonitoring at the Szczecin Diatom Summer School (25-28 August 2026)

# How to use the repository? There are two options:
1. Download the full repository in your local machine: Code > Download ZIP. Unzip the file and open `2026_diatom_summer_school.Rproj`
2. If you have a [GitHub account](https://github.com/) and can use [git](https://git-scm.com/), you can [clone the repo](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)
