# 2026_diatom_summer_school
Repository containing scripts and data for the exercises on diatom biomonitoring at the Szczecin Diatom Summer School (25-28 August 2026)

# How to use the repository? There are two options:
1. Download the full repository in your local machine: Code > Download ZIP. Unzip the file and open `2026_diatom_summer_school.Rproj`
2. If you have a [GitHub account](https://github.com/) and can use [git](https://git-scm.com/), you can [clone the repo](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)

# Repository structure
1. scripts: codes for running all the analyses sequentially 
2. data: diatom counts including the [Ebro Delta](https://doi.org/10.5281/zenodo.15113793) and Segura River (**unpublished**) datasets as well as associated environmental variables (water chemistry)

# Resources used
- [Diathor](https://github.com/limnolab/DiaThor) Version 0.1.6. Publication: [DOI](https://www.sciencedirect.com/science/article/pii/S0304380021003975)
- Ecological preferences of diatoms: [Mertens et al., 2025](https://www.sciencedirect.com/science/article/pii/S1470160X25001487?via%3Dihub)
- Indice de Polluosensibilité (IPS) or Specific Pollution Sensibility Index: [Coste, M 1992](https://www.documentation.eauetbiodiversite.fr/notice/etude-des-methodes-biologiques-d-appreciation-quantitative-de-la-qualite-des-eaux0)
